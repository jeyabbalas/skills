# Effect size
sources: downey2014-think-stats · ch 2 · p. 27–28

## Passages
> "An effect size is a summary statistic intended to describe (wait for it) the size of an effect. For example, to describe the difference between two groups, one obvious choice is the difference in the means." — downey2014-think-stats · ch 2 · p. 27

> "Another way to convey the size of the effect is to compare the difference between groups to the variability within groups." — downey2014-think-stats · ch 2 · p. 27

## Terms
Think Stats introduces the raw difference in means and **Cohen's d** = (x̄₁ − x̄₂)/s_pooled, with pooled variance (n₁s₁² + n₂s₂²)/(n₁ + n₂). It benchmarks d informally (male–female height ≈ 1.7 sd) rather than naming small/medium/large conventions.

## Questions
- How should a difference be reported when detectability (big n) and importance come apart?
- What denominator makes a difference comparable across studies with different units?
